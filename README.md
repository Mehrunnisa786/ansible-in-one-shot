## 📌 Overview

This repository is a complete **Ansible learning and automation project** designed to help understand Ansible concepts in one place — from beginner to advanced level.

It includes:
- Ansible installation
- Inventory setup
- Ad-hoc commands
- Playbooks
- Roles
- Variables
- Handlers
- Templates
- Service management
- User management
- Automation examples

Ansible is an open-source automation tool used for configuration management, application deployment, and infrastructure automation using YAML-based playbooks. 

---

# 🚀 What is Ansible?

Ansible is an agentless automation tool that connects to servers using SSH and automates repetitive infrastructure tasks using YAML playbooks. 

### ✅ Key Features

- Agentless Architecture
- SSH-based automation
- YAML playbooks
- Infrastructure as Code (IaC)
- Easy server provisioning
- Configuration management
- Application deployment
- Reusable roles and tasks
